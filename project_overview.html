Project overview

AI for blood-cell classification.

HematoVision uses a trained MobileNetV2-based TensorFlow model to classify uploaded blood-cell microscopy images into four classes. This interface keeps the original inference pipeline with a simple upload-and-classify workflow.

Model

MobileNetV2 transfer learning

Images are resized to 224 × 224 and passed through the same MobileNetV2 preprocessing used by the existing model.

Analysis

Direct image inference

The uploaded image is processed in memory for classification and is not stored in a database.

Deployment

Deployable Flask layout

Gunicorn, Docker, upload limits and a health endpoint are included for deployment.

Classes

Eosinophil · Lymphocyte · Monocyte · Neutrophil

The class order remains aligned with the existing application model configuration.
